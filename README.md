# حاسبة الصابون | معمل الطبيعة

حاسبة صابون باللغة العربية لدورة الصابون مع المدربة سلوى شرف — [www.salwalab.com](https://www.salwalab.com)

- حساب كمية القلوي (هيدروكسيد الصوديوم أو البوتاسيوم) والماء والعطر
- 149 زيتًا ودهنًا وشمعًا مع قيم التصبّن وخصائص الصابون والأحماض الدهنية
- ملخص للوصفة قابل للطباعة والحفظ بصيغة PDF، وأسماء INCI، وحفظ الوصفات وتحميلها بصيغة JSON

الموقع صفحة ثابتة (HTML وCSS وJavaScript) لا تحتاج إلى خادم: افتح `index.html` مباشرة أو انشره على GitHub Pages.
